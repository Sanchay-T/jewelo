# Omran context — image prompts

Use this file when generating or revising Caleums stills, style cards, or ads.  
Do not copy WhatsApp images into the public repo. Describe the construction; do not restyle the customer’s spelling.

## Always

- Exact approved name. If unknown, use `ASMA` (short) or `MUHAMMAD` (long). Never invent letters.
- 18K yellow gold unless the customize step says otherwise.
- Silent product still. No video, no lifestyle motion, no fake UI chrome on the gold.
- Cream / ivory studio for Deck A. Dark navy only for Deck B spec energy.
- Two jump rings, one chain. No extra charms, no second name unless asked.

Length class:

- Short: ASMA, ISMA, NUR (4 letters)
- Long: MUHAMMAD (8+). Preview must look wider/heavier, not the short plate stretched.

## Deck A — first-look cards

Prefix every prompt with:

`Professional jewelry product still, 18K yellow gold name pendant spelling {NAME} exactly, luxury studio, soft ivory background, one delicate cable chain, no extra letters.`

Then add one look:

| Look | Prompt cues |
| --- | --- |
| Classical writing | normal connected lettering, classical nameplate, clean polished gold, minimal or no diamonds |
| Floating Diamond Rails | open architectural nameplate with top and bottom rails, floating bezel-set round diamonds on the rails, linear structure, elegant spacing |
| Framed Minimal | clean block letters inside an open rectangular frame, corner diamonds plus optional side-bar accents, structure and symmetry |
| Diamond Constellation Frame | constellation-framed modern nameplate, bezel-set perimeter nodes implying a rectangle, negative space, implied geometry |
| Origami Ribbon | folded origami ribbon letters, continuous ribbon, geometric planes, sculptural depth, select fold-point diamond accents, rectangular silhouette |
| Faceted Origami | faceted origami lettering, sharp folds, princess-cut diamond accents, strong silhouette, premium render. English or Arabic as specified |

## Display modifiers

Append exactly one:

- Horizontal: `letters read left to right, wide nameplate`
- Vertical: `letters stacked or cascading downward`
- In the frame: `letters held inside a visible metal frame`
- Square: `compact square silhouette, name fills a square field`

## Deck B — customize only

Do not use these as the six first-look cards.

- Drop Origami: vertical cascade, entry diamond, north-star blue sapphire, pink accent, marquise exit, hidden side sapphires
- Stacked Origami: AS over MA, same journey stones
- Open-Frame Suspended: letters hung inside an open/octagonal frame, constellation nodes
- Art Deco: stepped frame, baguette-filled letters, sunburst, royal-blue sapphires
- Celestial / Constellation: orbital wireframe around diamond letters, north star
- Ribbon Flow: cursive gold ribbon script, same celestial stone language

Journey stone order if specified: entry → north star → personal accent → exit → hidden.

## Negative

`no video, no extra names, no extra charms, no mismatched spelling, no stretched short-name plate, no calligraphy-font picker UI, no four-camera storyboard as the hero`
