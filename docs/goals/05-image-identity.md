# Goal 05 — canonical identity and still-image generation

## Completion condition

Jewelo can produce controlled product and worn stills through provider adapters while preserving an approved canonical pendant identity and measuring quality against the frozen evaluation corpus.

## Required work

- Implement text normalization, approved typography/layout, deterministic SVG identity, stable fingerprint, and a future 3D/CAD boundary.
- Implement prompt releases and typed product/worn prompt builders.
- Implement the approved primary image adapter plus mock/fixture adapter; exact model ID is configuration.
- Generate four product directions concurrently and chain worn views only after identity QA.
- Implement deterministic and multimodal identity checks, rejection/retry policy, cost/latency lineage, spend/concurrency kill switches, and evaluation reports.
- Enable real calls only behind an explicit environment flag and a small approved budget.

## Verification

Run the frozen corpus/approved subset, publish identity/usability/latency/cost results, compare against the Phase 0 threshold, test moderation/provider outage and rollback, and have native-language review for relevant scripts.

## Stop condition

Draft PR into integration. Do not claim manufacturing-grade CAD or implement video/commerce expansion.
