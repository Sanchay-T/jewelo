# Goal 04 — canonical identity, prompt releases, and QA

## Objective

Make exact name/pendant identity deterministic and create the versioned prompt/verification engine that real providers will consume.

## Completion condition

For the approved multilingual fixture corpus, Jewelo produces stable canonical identity assets/fingerprints, compiles versioned provider requests, and evaluates synthetic good/bad outputs with deterministic and structured QA results.

## Required work

- Unicode normalization and script/language validation.
- Licensed font registry, shaping, deterministic SVG/mask/preview generation.
- Geometry/attachment/stone metadata and fingerprinting.
- Typed prompt compiler for product, worn, and motion.
- Code-based prompt releases/checksums/rollback.
- Deterministic OCR/contour/configuration checks.
- Structured visual-verifier adapter using mock fixtures initially.
- Evaluation corpus and reports from `docs/AI-MODEL-EVALUATION.md`.
- UI identity status and manual inspection evidence.

## Constraints

No broad paid generation. A tiny explicitly approved verifier smoke call is allowed only if credentials/budget are provided.

## Verification

Golden snapshot determinism, multilingual edge cases, malicious/invalid text, font/license manifest, synthetic mutation detection, prompt snapshot lineage, accessibility/UX review, adversarial review.

## Stop condition

Draft PR. Do not activate the real still pipeline.
