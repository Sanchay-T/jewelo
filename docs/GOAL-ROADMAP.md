# Goal roadmap

| Goal | Outcome | Explicitly excluded |
| --- | --- | --- |
| 00 Production foundation | exact monorepo, pinned toolchain, managed-service seams, CI, preview configuration, health surface | customer features and paid generation |
| 01 Product studio | complete responsive customer/operator shell and all generation states using typed mock gateways | real persistence and provider calls |
| 02 Supabase domain | Auth, RLS, SQL schema, private Storage, Realtime, repositories, outbox | real AI generation |
| 03 Durable generation | Trigger.dev orchestration with provider contract mocks, fan-out, retry, partial success, cancellation | paid model activation |
| 04 Identity/prompt/QA | deterministic pendant identity, prompt compiler, releases, validation corpus, verifier contract | broad real generations |
| 05 Real still generation | controlled GPT Image 2 product/worn pipeline and quality/cost evaluation | production motion and commerce |
| 06 Real motion | selected-first Runway motion, player, drift/format QA, retry/recovery | full commerce/launch |
| 07 Commerce/operator | estimates, quote/order snapshots, operator workflow, customer communication seams | production launch |
| 08 Hardening/launch | security, load, observability, retention, backup/restore, budgets, deployment, rollback, launch review | post-launch roadmap |

Each goal is a durable outcome, not a generic sprint. It may refine the next goal but must not silently absorb it.
